# Metro Launcher

<p align="center">
  <strong>Android-лаунчер в стиле quickshell metro (Linux Desktop) и Windows Phone Live Tiles.</strong><br>
  Строгая эстетика Fluent Acrylic: полупрозрачные плитки с аппаратным блюром, WP-список приложений с Jump Grid, динамические акценты из обоев и виджеты.
</p>

---

## Особенности

- 🪟 **Сетка живых плиток (Live Tiles)**: 4-колоночная модульная сетка с поддержкой произвольных размеров плиток (1×1, 2×2, 2×4, 4×2 и др.), плавным drag-and-drop перетаскиванием и тактильным откликом при нажатии.
- ❄️ **Акриловое стекло и фрост-эффект (Frosted Glass)**: Срез предблюренных обоев 1:1 ровно под каждой плиткой и аппаратный `RenderEffect` размытия на Android 12+ (API 31+).
- 🎨 **Умная палитра акцентов из обоев**: Алгоритм анализа изображения (квантование, скоринг сочности, нормализация светлоты и насыщенности), портированный из десктопного `metro-colors`. Лаунчер автоматически предлагает гармоничные акцентные цвета при каждой смене обоев.
- 🖼 **Встроенное кадрирование обоев**: Интерактивный инструмент обрезки с рамкой под точные пропорции экрана устройства, поддержкой pinch-to-zoom и панорамирования.
- ⚙️ **Полноценный центр параметров (Metro Settings Hub)**:
  - Настройка радиуса размытия (блюра);
  - Регулировка прозрачности подложки плиток (`glass`), меню/диалогов (`glassDeep`) и границ (`stroke`);
  - Выбор акцента из палитры обоев или произвольного цвета через спектральный пикер / HEX;
  - Мгновенное применение изменений на лету (live preview).
- 🚀 **Обновления по воздуху (OTA Updates)**: Автоматическая проверка новых релизов на GitHub, отображение чейнджлога, скачивание и бесшовная установка APK прямо внутри приложения.
- 📑 **Встроенные виджеты**:
  - 🌦 Погода Open-Meteo с аккуратными глифами Nerd Font;
  - 🎵 Системный аудиоплеер с управлением треками и прогрессом воспроизведения;
  - 📝 Заметки с интерактивным списком задач (ToDo);
  - 🕒 Часы и дата с быстрым запуском системного будильника и календаря;
  - 📱 Поддержка стандартных виджетов Android (AppWidget).
- 🔤 **Типографика Segoe UI Variable**: Аутентичные начертания `Segoe UI Variable Text/Display` и векторные иконки `Nerd Font`.

## Сборка и установка

### Требования
- JDK 17
- Android SDK 35 (minSdk 26 — Android 8.0+)
- Gradle 8.x+

### Сборка отладочной версии (Debug)
```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Сборка релизной версии (Release)
Для сборки релизной версии настройте ключи подписи в `local.properties`:
```properties
metro.storeFile=/path/to/metro-release.keystore
metro.storePassword=your_store_password
metro.keyAlias=your_key_alias
metro.keyPassword=your_key_password
```
Сборка APK:
```bash
./gradlew assembleRelease -x test
# Релизный APK: app/build/outputs/apk/release/app-release.apk
```

### Публикация релизов на GitHub
В проекте есть скрипт для автоматической сборки, создания тега и загрузки APK в GitHub Releases:
```bash
./tools/release.sh "Описание изменений релиза..."
```
